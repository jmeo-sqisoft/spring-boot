# MyBatis XML · SQL 포맷 가이드

MyBatis Mapper XML에 작성하는 SQL의 표기와 정렬 기준을 정리합니다.
SQL은 핵심 규칙과 상세 작성 기준에 따라 작성합니다. 문서 끝의 예시는 규칙을 적용한 형식을 보여 줍니다.

## 핵심 규칙

| 번호 | 항목 | 작성 기준 |
| --- | --- | --- |
| 01 | 대소문자 | SQL 키워드·함수명·데이터 타입은 소문자로 작성하고, 기존 식별자·문자열·바인딩 변수의 표기는 유지합니다. |
| 02 | 컬럼 별칭 | 새 컬럼 별칭은 `g_group`, `sct_name`처럼 소문자와 밑줄로 작성하고, 기존 식별자는 임의로 변경하지 않습니다. |
| 03 | 테이블 별칭 | `a`, `b`, `c`처럼 짧은 소문자를 사용하고, 서브쿼리 내부는 `x`, `y`처럼 바깥 참조와 구분합니다. |
| 04 | AS 표기 | 컬럼·서브쿼리 결과 별칭에는 `as`를 사용합니다. 테이블 별칭은 `as` 사용을 기본으로 하되 생략도 허용합니다. |
| 05 | 컬럼 구분 | 최상위 SELECT의 첫 식은 공백 6칸, 다음 식은 공백 4칸 뒤 `, `로 시작해 식의 시작 위치를 맞춥니다. |
| 06 | SELECT | 여러 식을 조회하면 `select` 다음 줄부터 작성합니다. 단일 컬럼 서브쿼리는 같은 줄 또는 다음 줄에 작성할 수 있습니다. |
| 07 | FROM·WHERE | `from 테이블명`, `where 조건식`처럼 키워드와 첫 대상을 같은 줄에 작성합니다. |
| 08 | JOIN·ON | JOIN과 대상은 같은 줄에 두고, `on`은 같은 줄 또는 다음 줄에 작성합니다. 이어지는 조건은 식의 시작 위치를 맞춥니다. |
| 09 | 파라미터 바인딩 | `#{...}`로 바인딩하고, `${...}`는 사용하지 않습니다. |
| 10 | 탭·공백 | 탭은 사용하지 않습니다. 기본 블록 들여쓰기는 공백 4칸이며 컬럼·조건의 수직 정렬에는 추가 공백을 사용합니다. |
| 11 | INSERT·UPDATE | 컬럼·값·대입식을 줄바꿈하고 선두 콤마를 사용해 시작 위치를 맞춥니다. |
| 12 | 문장 종료 | 세미콜론을 생략하고, 마지막 SQL 구문 뒤에서 줄을 바꿔 종료합니다. |

## 상세 작성 기준

### 기본 표기와 별칭

- SQL 키워드·함수명·데이터 타입은 `select`, `case`, `now()`, `varchar`처럼 소문자로 작성합니다.
- 새 컬럼 별칭은 `g_group`, `sct_name`, `sct_type`처럼 소문자와 밑줄로 작성합니다.
- 기존 스키마에 정의된 테이블·컬럼 이름의 대소문자와 문자열 리터럴의 값은 변경하지 않습니다.
- 컬럼 별칭은 해당 식의 마지막 구문 또는 닫는 괄호 뒤에 `as 별칭`으로 작성합니다.
- 테이블 별칭은 테이블 이름 뒤에 `as 별칭`으로 작성하는 것을 기본으로 하며, `테이블명 별칭` 형태도 허용합니다.
- `as`를 사용하면 양옆에 공백 한 칸을 둡니다.
- 같은 쿼리 블록의 별칭은 중복하지 않고, 모든 컬럼 참조는 해당 별칭과 일치시킵니다.
- 서브쿼리 내부에는 바깥 쿼리와 구분되는 별칭을 사용합니다. 상관 조건에는 참조 대상인 바깥 쿼리의 별칭을 명시합니다.

### SELECT와 컬럼 정렬

- 여러 식을 조회하는 `select`는 단독 줄에 작성하고, 다음 줄부터 컬럼을 나열합니다.
- 최상위 SELECT의 첫 식은 공백 6칸 뒤에 작성합니다.
- 다음 식은 공백 4칸 뒤에 `, `를 붙여 첫 식과 시작 위치를 맞춥니다.
- 콤마는 앞선 식의 줄 끝에 붙이지 않습니다.
- 단일 컬럼 서브쿼리는 `select 컬럼`을 같은 줄에 작성하거나 `select` 다음 줄에 컬럼을 작성할 수 있습니다.
- 컬럼을 다음 줄에 작성하는 경우 컬럼은 해당 `select`보다 안쪽으로 들여씁니다.
- 서브쿼리는 바깥 블록보다 안쪽에 배치하고, 내부 SELECT 목록의 선두 콤마와 식 시작 위치를 맞춥니다.

| 위치 | 정렬 형태 |
| --- | --- |
| 여러 식의 조회 시작 | `select` 단독 줄 |
| 최상위 첫 식 | 공백 6칸 + 컬럼 또는 식 |
| 최상위 다음 식 | 공백 4칸 + `, ` + 컬럼 또는 식 |
| 단일 컬럼 서브쿼리 | `select 컬럼` 또는 줄바꿈 형식 |
| 첫 테이블 | `from 테이블명 as 별칭` |
| 첫 조건 | `where 조건식` |
| 다음 WHERE 조건 | 공백 2칸 + `and 조건식` 또는 `or 조건식` |

### 공백과 CASE 정렬

- XML과 SQL 모두 탭을 사용하지 않습니다.
- 기본 블록 들여쓰기는 공백 4칸으로 하고, 컬럼·조건·괄호의 정렬에는 필요한 공백을 추가합니다.
- `case when`과 `case 컬럼 when` 두 형식을 모두 사용합니다.
- `when 조건 then 결과`는 같은 줄에 작성하고, `else 결과`는 다음 줄에서 `when`의 시작 위치와 정렬합니다.
- `end`는 대응하는 `case`의 시작 위치와 정렬합니다. 중첩 CASE의 각 분기에도 같은 기준을 적용합니다.
- SELECT 목록의 CASE가 끝나면 `end as 별칭`으로 닫습니다.
- 포맷을 맞추기 위해 SQL 문자열 내부의 공백이나 실제 값을 변경하지 않습니다.

### 서브쿼리와 조인

- SELECT 목록의 서브쿼리는 `, (`로 시작하고, 닫는 괄호 뒤에 `as 별칭`을 작성합니다.
- JOIN의 서브쿼리는 JOIN 키워드 뒤에 여는 괄호를 두고, 내부 쿼리를 들여쓴 뒤 `) as 별칭`으로 닫습니다.
- 일반 테이블 JOIN은 JOIN 키워드 뒤에 테이블과 별칭을 같은 줄에 작성합니다.
- 조인 조건을 한 줄에 작성하는 경우 대상 뒤에 `on 조건식`으로 이어 씁니다.
- 조건을 여러 줄로 나누는 경우 `on`을 다음 줄에 두고, 이어지는 `and`·`or` 뒤의 식 시작 위치를 맞춥니다.
- JOIN 조건은 `on`, 조회 대상의 필터 조건은 `where`에 작성합니다.
- WHERE의 추가 조건은 최상위 기준 공백 2칸 뒤 `and`·`or`로 시작합니다.
- IN 서브쿼리는 `컬럼 in (`으로 열고, 내부 쿼리를 들여쓴 뒤 닫는 괄호를 별도 줄에 작성합니다.
- AND와 OR를 섞으면 의도한 조건 묶음을 괄호로 명시합니다.

### CTE 이름과 구분

- CTE를 추가하는 경우 이름에 `cte_` 접두사를 붙입니다. 예: `cte_inp`, `cte_summary`.
- 여러 CTE는 줄을 바꾼 뒤 선두 콤마로 구분하고, 내부 쿼리는 서브쿼리와 같은 공백 기준으로 정렬합니다.

### 파라미터 바인딩

- Mapper에 전달하는 값은 `#{...}`로 바인딩합니다. `${...}`는 사용하지 않습니다.
- 바인딩 변수 이름은 Java 프로퍼티나 Mapper 파라미터와 일치시킵니다.
- SQL에 고정된 문자열·숫자는 리터럴로 작성할 수 있습니다. 요청이나 서비스에서 전달받는 값은 반드시 바인딩합니다.

### 데이터 입력과 수정

- INSERT 컬럼과 VALUES 값은 여는 괄호 다음 줄부터 작성하고, 항목 순서를 일치시킵니다.
- 각 목록의 첫 항목은 공백 6칸, 다음 항목은 공백 4칸 뒤 `, `로 시작합니다.
- `) values (`는 같은 줄에 두고, 마지막 닫는 괄호는 별도 줄에 작성합니다.
- UPDATE의 첫 대입식은 `set` 뒤 공백 3칸을 두고 작성합니다.
- 다음 대입식은 공백 4칸 뒤 `, `로 시작하고, WHERE 조건은 다음 줄에 작성합니다.
- 비교·대입 연산자 양옆에는 공백을 둡니다.

### 문장 종료

- SELECT·INSERT·UPDATE 모두 문장 끝에 세미콜론을 작성하지 않습니다.
- 마지막 구문 뒤에서 줄을 바꾸고 SQL 블록을 종료합니다.

## SQL 작성 예시

### 조회 · 서브쿼리 · 조인

```sql
select
      c.fg_seq
    , case when a.sc_type = 1 then 'F'
           else 'N'
      end as g_group
    , (
        select
              sctName
            , sctId
        from sampleZ as x
        where x.sct = a.sct
      ) as sct_name
    , case a.sct when 'A203' then 'S'
                 else case when a.sc_type = 1 then 'F'
                           else 'N'
                      end
      end as sct_type
    , a.sct
    , now() as current_date
from sample as a
inner join (
        select y.fg_seq
        from sampleX as x
        inner join sampleY as y on y.code = a.cust_code
        where a.svc_date >= getdate()
    ) as b on b.fg_seq = a.fg_seq
left outer join sample1 as c on c.fg_seq = a.fg_seq and c.sct = a.sct and ((a.sc_type = 1 and c.gGroup = 'F') or (a.sc_type = 2 and c.gGroup = 'N'))
left outer join sample2 as d
             on d.fg_seq = c.fg_seq
            and d.sct = c.sct
            and ((d.sc_type = 1 and d.gGroup = 'F') or (d.sc_type = 2 and d.gGroup = 'N'))
where a.op_type = 'I'
  and a.isn in (
        select x.isn
        from sample2 x
        where x.cno = a.cno
  )
```

### 데이터 입력

```sql
insert into sample (
      col_1
    , col_2
) values (
      1
    , 'a'
)
```

### 데이터 수정

```sql
update sample
set   col_2 = 'b'
    , col_3 = 'c'
where col_1 = 1
```
